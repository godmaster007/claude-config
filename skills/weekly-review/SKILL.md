# Weekly review

This skill is read only. Never send, reply to, archive, label or change any email, event or file.

## Gather
1. **Calendar** (Google Calendar): the meetings held Monday through today, and next week's events. Flag next week's events that need prep (external attendees, interviews, client calls, anything with a doc attached).
2. **Inbox** (Gmail): threads from this week where someone is waiting on Nick (he was asked a question, was sent a request, or hasn't replied for over 48h). Skip newsletters, receipts and notifications.
3. **Claude project**: if project tools are available, list the threads active this week with their state (done, waiting on Nick, or blocked).
4. **Drive** (optional): docs Nick edited this week, only if asked.

## Write
Produce one message under 25 lines, with these headings in this order:
- **Needs you**: the items waiting on Nick, oldest first, one line each with a link.
- **Done**: what got finished this week.
- **Still open / blocked**: what's open, and who it is waiting on.
- **Next week**: events needing prep, and the top 3 priorities.

Lead with the item that matters most. Give a link for every email, event or thread. If a source failed (for example a connector being down), say so in one line at the end rather than skipping it silently.
